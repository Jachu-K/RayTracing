**C# Implementation of a Ray Tracer**

A from-scratch implementation of a ray tracing engine built entirely in C#.

**Implementation Progress:**
- ✅ Basic ray-sphere intersection
- ✅ Camera and viewport setup
- ✅ Material system (diffuse, metal, dielectric)
- ✅ Anti-aliasing and multi-sampling
- 🔄 Advanced features in development

**Features:**
- Custom vector mathematics library
- Physically-based rendering materials
- Configurable camera and scene setup
- Multi-threaded rendering
- PPM image output format

**Project structure:**
- `src/` - all C# source files
- `assets/models/` - OBJ models and related resources
